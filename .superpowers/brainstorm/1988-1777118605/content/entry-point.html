How should users enter the Creative Performance Explorer?

The entry point determines the mental model for the whole page. Which flow feels most natural for an advertiser?

A

Filter-First

Sidebar with all filters (advertiser, campaign, format, vertical, country, OS, date range). The main area shows a ranked creative list + charts that update live. No pre-selection needed — the page is always populated with the full dataset by default.

B

Creative-First (Deep Dive)

Start by searching / selecting a specific creative. A detailed profile page appears: KPIs, performance vs. peers, geo breakdown, time trend, and the actual ad image. Comparison peer group is auto-set to the same campaign but can be changed.

C

Tabbed Hybrid

Two tabs at the top: "Overview" (filter-driven portfolio view, answer macro questions like "how are gaming ads doing in Europe?") and "Deep Dive" (select one creative, see full profile + comparisons). Same filter sidebar shared across both tabs.
